# FinKG-News

A framework for constructing a financial knowledge graph from news articles and generating credit risk reports using large language models.

This repository contains the code and notebooks for the *Evidence-Supported Credit Risk Report
Generation Using News-Centric Financial Knowledge Graph* paper:

- **Short version** — published at [DEXA](https://example.com/dexa) (placeholder)
- **Long version** — [arXiv](https://arxiv.org/) preprint (placeholder)


## Modules

This repository contains two main modules. See each module's README for details:

- **[FinKG-News-Framework](FinKG-News-Framework/README.md)**: pipeline to build the financial knowledge graph.
- **[Credit Risk Report Generation](Credit-Risk-Report-Generation/README.md)**: framework to generate credit risk reports using the graph and external data sources.
