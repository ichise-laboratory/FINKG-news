# Financial Risk Report Generation

Finally, to showcase the potential of FinKG-news we explored the Financial Risk Report Generation use case. This directory contains resources and notebooks for generating financial risk reports using FinKG-news and LLMs.

## Contents

- **financial_risk_report_generation.ipynb**  
  The main notebook. Use it to generate different reports for specific companies and years.

- **output_reports.txt**  
  Example output of reports generated by the LLM.

- **risk_metrics.ipynb**  
  Experimental notebook for exploring risk metrics available from the `yfinance` library.

- **event_graph_rag.ipynb**  
  Experimental notebook for integrating LangChain with Neo4j and Graph RAG. (This approach was discarded in favor of the simpler query and prompt method in the main notebook.)


## Setup

1. **Create a virtual environment**  
   ```sh
   python -m venv venv
   source venv/bin/activate  # On Windows: venv\Scripts\activate
   ```

2. **Install requirements**  
   ```sh
   pip install -r requirements.txt
   ```
3. **Set up your OpenAI API key**  
   - Get your API key from [OpenAI](https://platform.openai.com/account/api-keys).
   - Add your key to the `.env` file as follows:
     ```
     OPENAI_API_KEY=your_openai_api_key_here
     ```
   - Other open-source models (e.g., Llama, Mistral) can also be used with little modifications.

## How to Generate Reports

To generate financial reports, simply run he code in `financial_risk_report_generation.ipynb`.  
You can modify the companies and years for which reports are generated by editing the following list in the notebook:

```python
report_data_list = [
    {
        "company_name": "CoreCivic, Inc.",
        "company_cik": "0001070985",
        "company_ticker": "CXW",
        "year": "2022"
    },
    {
        "company_name": "CoreCivic, Inc.",
        "company_cik": "0001070985",
        "company_ticker": "CXW",
        "year": "2025"
    },
    # Add more companies and years as needed
]
```
